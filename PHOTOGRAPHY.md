# Bread Co product photography — shot list & how-to

**Status:** 19 of 67 products have real Bread Co photography. 48 to go.

The ten photos already on the site were shot at the bakery on the stainless
bench and on baking parchment. They look consistent because they were all shot
the same way, in the same place, in the same light. **The single most important
thing is to keep doing exactly that** — one more session in the same spot will
match perfectly. Stock photography will not, which is why we are not using it.

---

## The setup (repeat what you already did)

| | |
|---|---|
| **Surface** | Baking parchment on the stainless bench — same as the existing shots |
| **Light** | Existing bakery light, no flash. Shoot in the same part of the day as last time |
| **Angle** | Two per product: one at ~45°, one straight down |
| **Framing** | One product filling the middle of the frame, room around all four edges for cropping |
| **Orientation** | Landscape where possible |
| **Phone** | Same phone, HEIC is fine, highest quality, no filters or portrait mode |

### Four things to avoid

1. **No captions burnt into the photo.** The last batch had red text labels
   baked into the image. They had to be cropped out, which cost framing on
   several shots. Put the product name in the filename or send a list instead.
2. **One product per frame.** Several shots had four loaves in one photo, so it
   was guesswork which loaf the label referred to.
3. **Nothing else in shot** — no bins, mixers, boxes or hands in the background.
4. **Don't crop tight.** Leave space around the product; cropping happens later.

## Sending them over

Drop the files in a folder and tell me where. Name them after the product if you
can — `seven-grains-sourdough-650.heic`, `patti-pav.heic` — otherwise send a
list in the same order as the files.

HEIC straight off the phone is fine. I handle the rest: convert, crop to 4:3,
grade to match the existing shots (exposure, contrast, saturation, sharpening),
export web-optimised, wire each one to its product, write the alt text and
deploy.
